# AutoMusic 음악 생성 AI 조사

조사일: 2026-11-02. 공식 개발 문서·요금표·약관 및 호스팅 제공자의 자체 API 문서를 기준으로 조사했다. 실음원 비교, 한국어 가창 품질 평가, 유료 호출은 수행하지 않았다. 아래 순위는 **기능·연동·서비스 제공 조건에 따른 검증 우선순위**다.

## 프로젝트에 필요한 것

- 프롬프트에서 보컬·가사가 있는 노래 생성. 직접 입력한 한국어 가사도 사용.
- 생성 결과를 자체 저장소에 보관하고 재생·다운로드.
- 가사·설정 수정 후 새 버전 생성. 원본 음원과 이력 보존.
- 사용자가 선택한 버전에서만 별도 유사도 검사 실행.
- 향후 외부 음원 등록·유통 연결. 생성 서비스 이용권과 유통사 접수 조건은 별도로 확인.

## 추천

**추가 연동은 Mureka를 먼저 검증하고, Lyria를 비용 비교 후보로 둔다.** Mureka는 한국어 지원과 고객 앱 제공 근거가 명시되어 있고 구간 편집 API도 있어 장기적인 제작 흐름에 잘 맞는다. 이는 음질 우위에 대한 결론이 아니다. 신규 계정의 API 접근·충전 조건과 실제 가창 결과를 확인한 뒤 확정한다.

이미 작성한 ElevenLabs 어댑터는 첫 실제 생성 검증에 활용할 수 있다. 다만 이것을 상용 SaaS 공급자 확정으로 해석하지 않는다. ACE-Step은 GPU 추론 운영 자체를 포트폴리오에 추가하려는 단계에서 검토한다.

## Mureka

공식 FAQ는 한국어를 지원 언어로 명시한다. 유료 API 출력의 상업 사용·플랫폼 배포를 안내하며, 웹 서비스 구독과 API 잔액은 별개다. API 충전금은 마지막 충전부터 12개월 유효하다. [공식 FAQ](https://platform.mureka.ai/docs/en/faq.html)

공식 API 계약 1.2는 고객 웹·앱에 서비스를 통합해 최종 사용자에게 제공하는 것을 허용한다. 3.2는 법이 허용하는 범위의 출력 권리를 고객에게 배정한다. 이 조항이 개별 생성곡의 법적 저작권 성립이나 제3자 권리 비침해를 보장하는 것은 아니다. [API 계약](https://platform.mureka.ai/service_terms.pdf)

- `POST /v1/song/generate`: 직접 가사로 생성, 비동기 task ID 반환. [문서](https://platform.mureka.ai/docs/api/operations/post-v1-song-generate.html)
- `POST /v1/song/easy-generate`: 프롬프트·스타일로 생성. [문서](https://platform.mureka.ai/docs/api/operations/post-v1-song-easy-generate.html)
- `POST /v1/song/region-edit`: 시간 구간과 가사를 지정해 편집. 목소리·멜로디의 완전 보존은 별도 검증 대상. [문서](https://platform.mureka.ai/docs/api/operations/post-v1-song-region-edit.html)
- 공식 변경 이력에는 2026-08-28의 9.5 모델 및 2026-10-29의 가사 기반 생성 길이 제어 추가가 기록되어 있다. 정확한 길이 범위·요청 필드는 연동 전 스키마 확인 필요. [변경 이력](https://platform.mureka.ai/docs/en/changelog.html)

직접 API 요금 화면은 이번 공개 문서 조회로 검증하지 못했다. 대신 **별도 호스팅 경로인 fal**의 Mureka 9.5 페이지는 가사 제공 $0.15/곡, 프롬프트만 제공 $0.50/곡, 요청당 1곡으로 표시한다. 이는 Mureka 직접 계정의 견적이 아니다. 해당 경로를 선택하면 fal의 이용·과금 조건도 적용된다. [fal 요금·모델 페이지](https://fal.ai/models/mureka/v9.5/generate/song)

## Google Lyria

Gemini API의 `lyria-3.5`와 `lyria-3-clip-preview`는 보컬·가사·반주를 생성한다. 직접 가사를 프롬프트에 넣을 수 있다. Clip은 30초 고정이고 3.5는 수분 길이를 프롬프트로 유도한다. **정확한 60초 보장이나 기존 음원의 대화형 수정은 지원한다고 볼 수 없다.** 다국어 생성은 안내하지만 이번 조회에서 한국어를 명시한 API 지원 목록은 확보하지 못했다. 한국어 발음·가사 반영을 실청해야 한다. [생성 가이드](https://ai.google.dev/gemini-api/docs/music-generation)

3.5는 $0.08/곡, Clip은 $0.04/곡이고 무료 API 할당은 없다. 단순 계산으로 100회 생성은 각각 $8, $4다. [공식 요금](https://ai.google.dev/gemini-api/docs/pricing)

Gemini API 약관은 전문·비즈니스 목적의 개발자 사용을 전제하고 Google이 생성물 소유권을 주장하지 않는다고 설명한다. 연령·지역 등 API 클라이언트 조건도 적용된다. 이를 무제한 유통 보증으로 해석하지 않는다. [API 약관](https://ai.google.dev/gemini-api/terms)

현재 AutoMusic의 수정은 설정을 불러와 새 음원을 만드는 방식이므로 붙일 수 있다. 다만 UI의 고정 길이 선택을 모델별로 구분하고, 나중에 구간 편집이 필요하면 다른 제공자의 편집 기능을 연결해야 한다. 연주용 실시간 모델인 Lyria RealTime과 보컬 생성 모델을 혼동하지 않는다.

## ElevenLabs

공식 Music v2.5는 보컬·다국어·composition plan·inpainting을 지원한다. 이번 조사에서는 한국어 가창을 명시한 지원 목록이나 자체 실청 근거를 확보하지 못했다. TTS의 한국어 지원 목록을 Music 지원 근거로 사용하지 않는다. [Music 기능](https://elevenlabs.io/docs/overview/capabilities/music)

API 요금표는 $0.15/분으로 표시하면서 FAQ의 계량 설명은 per-generation으로 적고 있다. 결제 화면·계정의 실제 Music 과금 기준을 확인한 뒤 예산을 정한다. [API 요금](https://elevenlabs.io/pricing/api)

2026-10-09 음악 약관상 스트리밍 배포는 Creator 이상에 허용되지만, 모델 재판매·음악 라이브러리 제공에는 별도 서면 허가 조건이 있고 음악 생성 전문 서비스의 공동 브랜딩 조항도 있다. 자체 제품에서 출력만 제공하는 경우와 모델/API 접근을 재판매하는 경우의 정의도 다르다. **유료 API 키만으로 AutoMusic SaaS의 모든 제공 방식이 허용된다고 결론 내리지 않는다.** [음악 약관 4절·Exhibit A](https://elevenlabs.io/music-terms)

현재 코드는 `mp3_48000_192`를 요청한다. API 문서는 이를 v2의 기본 출력으로 설명하지만 약관의 고품질 다운로드 표에는 플랜 차이가 있어 이용 계정에서 적용 범위를 확인해야 한다. 또한 `store_for_inpainting`은 현재 전송하지 않으므로 기존 코드만으로 제공자 구간 편집까지 연결된 상태는 아니다. [생성 API](https://elevenlabs.io/docs/api-reference/music/compose)

## AutoMusic 적용 순서

1. 기존 ElevenLabs 연결로 한국어 보컬 1곡의 생성·저장·재생을 검증한다. 접근 가능한 계정이 있을 때 수행한다.
2. Mureka의 신규 접근·요금 조건을 확인하고 어댑터를 추가한다. task ID를 저장하고 상태를 조회하는 구조가 필요하다. 기존 API/DB/워커/버전 이력 흐름은 재사용한다.
3. Lyria를 동일 가사 비교 대상으로 추가해 비용과 가창 결과를 평가한다. 제공자별 길이·구간 편집 지원 차이를 UI에 반영한다.
4. 각 음원 버전의 파일을 확정·보관한 후, 사용자가 검사 버튼을 누를 때만 유사도 분석 작업을 접수한다. 생성 제공자 내부 필터가 우리 음원 DB 기반 검사를 대신하지 않는다.
5. 외부 등록은 사용자 검토, 제공자 사용 조건, 유통사 요구 메타데이터를 연결하는 후속 단계로 둔다.

제공자별로 모델 ID·외부 task ID·원본 요청·실제 곡 길이·출력 형식·실제 비용·생성 당시 적용 조건을 기록하는 방향을 권장한다. 현재 모든 항목이 구현된 것은 아니다. 유료 생성의 접수 결과가 불명확하면 새 요청을 자동 제출하지 않는 기존 정책도 유지한다.

## 실제 비교 실험안 — 아직 미실행

- 직접 쓴 동일 한국어 가사를 사용해 발라드·인디 팝·랩 3종 × 2회, 제공자당 6곡으로 시작한다. 길이는 각 모델의 지원 범위 안에서 맞추고 실제 길이를 기록한다.
- 발음·가사 누락/변형·노래 구조·음질을 블라인드 청취로 평가한다. 한국어가 지원된다는 사실과 좋은 한국어 노래가 나온다는 평가는 분리한다.
- 요청 접수→재생 가능한 파일 저장까지의 시간, 실패율, 청구액을 기록한다. 6곡에서 얻은 지연 분포로 운영 환경의 p95를 주장하지 않는다.
- 전체 재생성과 구간 편집은 별도 실험으로 둔다. “가사만 변경” 요청 시 변경 구간 밖의 멜로디·보컬·편곡 유지 여부를 확인한다.
- 6곡 기준 단순 생성비 예시는 Lyria 3.5 $0.48, Clip $0.24, fal Mureka 가사 입력 $0.90, 프롬프트만 입력 $3.00이다. 직접 계정 최소 충전액과 편집 호출 비용은 이 계산에 포함하지 않았다.
